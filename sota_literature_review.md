## Patent US12071162B2 - Pull-over location selection using machine learning

This patent describes process to select optimal pull-over location by assigning likelihood score to all available candidate pull-over locations. This score is calculated based on "features" like distance of the actual pull-over location, distance from the curb, distance from the various other objects like fire hydrant or bus stop etc. 

## Patent US20220326711A1 - Evaluating pullovers for autonomous vehicles

This patent proposes a simulation framework to evaluate how vehicle control performs for a pull-over. That way, developers can assess whether changes introduces improves or degrades pull-over performance. 

## Patent US11034351B2 - Planning stopping locations for autonomous vehicles

This patent describes speed planning while stopping. It marks "clear" regions like bus stop or fire hydrant where AV should not stop but it can drive through those regions towards stopping location.

## Patent US20220139227 - Passenger walking points in pick-up/drop-off zones

This patent describes method to find an available pickup/drop-off zone (PDZ). While selecting PDZ, system accounts for distance of the PDZ from passenger, likelihood that PDZ will be available, passenger's desire/ability to walk.
